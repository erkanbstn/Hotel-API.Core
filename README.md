# Otel API'si

Oda, rezervasyon, personel ve misafir mesajlarını sunan otel API'si.

## Ne var

Rezervasyon, oda, personel, mesaj ve yorum uçları ayrı controller'lardadır. Kimlik doğrulama ve JWT kullanılır.

## Çalıştırma

Çözümdeki API projesinde `dotnet run` kullanın. Bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET 6, Entity Framework Core, SQL Server, Identity ve FluentValidation.
